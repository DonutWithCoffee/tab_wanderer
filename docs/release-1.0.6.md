# tab_wanderer 1.0.6 — очистка проданных штрихкодов Ozon

Дата подготовки: 18 ноября 2026 года. Статус: кандидат на публикацию, не опубликован.

## Что нового (popup / Chrome Web Store)

- **Проверка проданных ШК.** Отдельная страница поиска ШК проданных товаров в завершённых Ozon-заказах. Подтверждённые совпадения с текущим списком Ozon можно просмотреть и удалить вручную.
- **Автоматическая сверка при сборке.** При открытии Ozon-заказа расширение сверяет актуальные ШК карточек с операциями продажи в свежей истории склада и проверяет связанные завершённые Ozon-заказы.
- **Автоочистка перед добавлением.** При включённой настройке подтверждённые проданные ШК удаляются из Ozon перед добавлением новых. На странице сборки виден раскрываемый список кандидатов по артикулам с номерами заказов продажи.
- **Независимые настройки с защитой.** Автопроверку и автоудаление можно включать отдельно. Выключение автопроверки автоматически выключает и блокирует удаление проданных ШК, включая ручное удаление из этой панели.
- **Понятный итог очистки.** После успешного автоудаления показывается количество удалённых ШК, старые кандидаты сбрасываются, повторное удаление блокируется.
- **Расширенная диагностика.** Логи содержат подтверждённые ШК и связанные заказы, отдельные непроверенные заказы и сведения о причинах отсева.

## Технические замечания

- Ручное сканирование и автоматическая очистка разделены; проверка `productItem.type` не блокирует автоматическое сопоставление, поскольку поле отсутствует в API складской истории. Для автоматического подтверждения нужны точное совпадение артикула и ШК, операция продажи и проверенный завершённый Ozon-заказ.
- Механизм добавления новых ШК и защиту от мультиштрихкодов при добавлении не ослабляли.
- Фильтр исключает ШК текущей сборки; неподтверждённые и непроверенные заказы не становятся кандидатами на удаление.
- Изменения не требуют новых разрешений браузера либо новых host_permissions.
- Ручное тестирование в реальных заказах: 2089-181126 — 5 подтверждённых ШК и успешное удаление со слов пользователя; 3912-160926 — обработка двух артикулов, для одного заказа ошибка проверки; 4877-181126 — автоудаление прошло, после чего до этой версии выявлено и исправлено сохранение старого состояния панели.
- Отправка в Chrome Web Store и публикация отдельно подтверждаются после локальной проверки и commit/push.
