## Риски на будущее (не исправлялись в этом релизе)

1. **Высокий — Angular snapshot / SPA lifecycle.** Извлечение полных ШК зависит от живого контроллера и лимитированного обхода. Проверенный fallback панели покрывает часть сбоев, но не гарантирует полного снимка сразу после смены маршрута. Не менять без новых интеграционных тестов.
2. **Средний — конкуренция асинхронных операций.** Обновления панели, фоновые проверки и подтверждения POST используют несколько источников состояния. Важно проверять соответствие orderId/actionId и актуальность сообщений после переходов.
3. **Средний — большой объём связанного кода.** `content.js`, `background.js` и пара Ozon bridges содержат много связанных сценариев. Переупорядочивание и дедупликация без тестов может нарушить проверенные защитные условия.
4. **Средний — ограниченная наблюдаемость UI.** Диагностика background подробна, но потери/восстановления DOM-панели не во всех случаях отражаются в экспортируемом логе.
5. **Низкий — объём диагностики.** Журнал ограничен по числу записей и байтам; старые данные вытесняются. Это важно для воспроизводимых производственных проблем.

Ни один из этих пунктов сам по себе не доказательство нового пользовательского бага. Изменения в этом пакете: только релизная версия, тесты на неё, документация и патчноут.
