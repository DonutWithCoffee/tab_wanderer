# tab_wanderer 1.0.5 — заметки к выпуску

## Для пользователей (popup и Chrome Web Store)

- **Резерв из поставки.** На странице поставки появилась кнопка «Собрать резерв под процен»: перенос позиций и количеств в предварительно созданный пустой заказ с проверкой результата.
- **Двусторонняя синхронизация Ozon.** При сборке штрихкоды добавляются в Ozon, при разборке — удаляются только штрихкоды подтверждённых разобранных единиц.
- **Удобная ручная проверка.** В панелях сборки и разборки — списки штрихкодов, сгруппированные по товарам, проверка в Ozon и контролируемые ручные действия.
- **Исправлена повторная сборка.** Новые ШК записываются в Ozon после подтверждения складской операции без перезагрузки страницы.

## Технические примечания (не показывать пользователям)

- Версия: `manifest.json`, `version.js`, `popup.js` → `1.0.5`.
- Настройки автоматического добавления и удаления независимы, обе включены по умолчанию.
- Разборка: только подтверждённые `product_item.id`; групповые и неопределённые типы исключены.
- Сборка: захват `product_item.id`/ШК до POST, подтверждение серверным ответом, затем существующая запись и повторная проверка Ozon.
- При невозможности однозначного сопоставления выполняется безопасный пропуск с диагностикой.
- Резерв из поставки: только пустой legacy-заказ, перенос последовательными проверяемыми запросами; авторезерв менеджер включает самостоятельно.
- Новые разрешения `permissions` и `host_permissions` не добавлены.
- Автоматический тестовый baseline из пользовательского архива: `412 pass / 0 fail`; контроль пакета фиксируется при сборке.
- На реальном заказе подтверждена повторная сборка одной единицы без F5, запись и read-after-write проверка Ozon.
- CWS submission и публикация на момент подготовки **не выполнены**.
